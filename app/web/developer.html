Access and safety

Open to test, bounded by design

Workspace ID
Names the tenant your key is scoped to. It is chosen by you and carries no privilege of its own.
API key
Authenticates requests, determines the tenant and scope, expires automatically, and can be revoked.

Product boundary

This API supports applicant-controlled preparation. It rejects detected identifiers, persists no raw letter text, and has no endpoint that contacts an insurer, agency, or third party.

  • Only a SHA-256 key digest is persisted.
  • The key expires automatically after seven days.
  • No credential is placed in browser storage.
  • The public judge workflow stays credential-free.
