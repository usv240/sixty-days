What this key can do

This API supports applicant-controlled preparation. It rejects detected identifiers, persists no raw letter text, and has no endpoint that contacts an insurer, agency, or third party.

  • The server derives the tenant from the key.
  • Only a SHA-256 key digest is persisted.
  • The key expires automatically after seven days.
  • You can revoke it from this page at any time.

Use it responsibly

Temporary access is intended for evaluation and small beta integrations. Do not place the key in frontend source, Git, screenshots, or public posts.

Need permanent access?

Operator-issued keys use the same scoped boundary but are rotated through Google Secret Manager. See the repository API guide for provisioning and revocation.

Before broader rollout

Place API Gateway in front of the service for per-consumer quotas, abuse controls, and formal onboarding. The current Cloud Run cap bounds infrastructure cost but is not a substitute for quotas.
