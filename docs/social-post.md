A disaster-assistance decision letter can start a short appeal clock while records are still
scattered across insurers, public offices, and a damaged home.

Sixty Days is a deployed deadline keeper. It preserves the letter's exact reason, registers eight
durable wakes, checks observable evidence framing, prepares applicant-controlled requests, and
builds a visibly partial draft packet. It never sends, submits, predicts eligibility, or acts as a
lawyer.

Built on Cloud Run, Firestore, Cloud Scheduler, Cloud Trace, Gemini 3.5 Flash, Gemma 4, Gemini 3.1
Flash Image, and Veo 3.1 Fast.
